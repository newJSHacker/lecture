# Software-rasterizer kernel and demos

Teaching Canvas `ImageData` demos for [[Computer Graphics/00 Lectures]].

- Open [index.html](index.html).
- Copy functions from [kernel.js](kernel.js). Prefer copying into a student starter.
- [raster.js](raster.js) is an rAF + `putImageData` loop, not a production engine.

Serve this folder if `file://` is blocked: `npx serve` or `python -m http.server`.
