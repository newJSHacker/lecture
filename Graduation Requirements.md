
A modern program like **Interactive Graphics and Web Technologies (IGWT)** should require more than just a graduation thesis. Employers and graduate schools want evidence that students can **design, build, document, and present** real systems.

I would organize the graduation requirements into several deliverables.

|Deliverable|Purpose|Weight|
|---|---|--:|
|Graduation Thesis|Demonstrates research and technical writing|20%|
|Capstone Project|Demonstrates engineering and implementation skills|40%|
|Project Demonstration|Demonstrates communication and presentation|10%|
|Portfolio Website|Showcases work for employment|10%|
|Technical Documentation|Ensures maintainability and reproducibility|10%|
|Oral Defense|Evaluates understanding and decision-making|10%|

## 1. Graduation Thesis

A thesis should resemble a professional conference paper rather than a simple project report.

Typical length:

- 50–100 pages (depending on university regulations)
- A shorter undergraduate model (20–30 pages) is in [[05 Sample Graduation Thesis]]
    

Suggested structure:

1. Introduction
    
2. Background and literature review
    
3. Problem definition
    
4. System design
    
5. Algorithms and architecture
    
6. Implementation
    
7. Experimental evaluation
    
8. Performance analysis
    
9. Discussion
    
10. Future work
    
11. References
    
12. Appendices
    

Students should cite academic literature and justify their technical decisions with experiments or benchmarks.

---

## 2. Capstone Project

The thesis should be accompanied by a substantial software system.

Examples include:

- Interactive product configurator
    
- Medical visualization platform
    
- Scientific visualization system
    
- Architectural walkthrough
    
- WebXR museum
    
- AI-assisted design tool
    
- Interactive data storytelling platform
    
- Real-time fluid or particle simulation
    
- Educational graphics application
    

This project should demonstrate the skills acquired throughout the curriculum.

---

## 3. Source Code

Students should submit:

- Complete source code
    
- Clear folder structure
    
- Build instructions
    
- Installation guide
    
- Dependency list
    
- License
    
- README
    

The project should be reproducible on another computer.

---

## 4. Portfolio Website

By graduation, every student should maintain a professional portfolio that includes:

- Biography
    
- Resume/CV
    
- Technical skills
    
- Major projects
    
- Live demos
    
- Videos
    
- GitHub links
    
- Contact information
    

This becomes a valuable asset for job applications.

---

## 5. Technical Documentation

Students should document:

- System architecture
    
- API documentation
    
- UML or component diagrams
    
- Rendering pipeline
    
- Asset pipeline
    
- Performance analysis
    
- User manual
    
- Developer guide
    

Professional documentation is often as important as the implementation itself.

---

## 6. Demonstration Video

A polished 5–10 minute video should:

- Explain the problem
    
- Demonstrate the application
    
- Highlight technical features
    
- Discuss performance
    
- Summarize future improvements
    

This is useful for assessment and for the student's portfolio.

---

## 7. Oral Defense

A typical defense (30–45 minutes) could include:

- 15–20 minute presentation
    
- Live demonstration
    
- Questions from the examination committee
    
- Discussion of design choices, algorithms, and limitations
    

The defense evaluates both technical understanding and communication skills.

---

## 8. Public Exhibition (Recommended)

Instead of limiting assessment to an examination room, organize an annual showcase where students present their projects to:

- Faculty
    
- Industry partners
    
- Alumni
    
- Other students
    
- Prospective employers
    

This creates networking opportunities and motivates students to polish their work.

---

## Example Graduation Package

Each graduate submits:

- Graduation thesis (PDF)
    
- Capstone application
    
- Source code repository
    
- Portfolio website
    
- Technical documentation
    
- Presentation slides
    
- Demonstration video
    
- Project poster

|---|---|

### Should there be a Graduation Thesis?

Yes, but in a program like **IGWT**, the thesis should be **project-based** rather than purely theoretical. The written thesis explains the research, design decisions, implementation, and evaluation of the capstone project, while the software itself demonstrates practical competence. This combination aligns well with programs in computer science, graphics, and software engineering, ensuring graduates leave with both academic credentials and a portfolio that is directly relevant to industry.
