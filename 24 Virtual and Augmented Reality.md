# Virtual and Augmented Reality

A 15-week university course for the **Interactive Graphics and Web Technologies (IGWT)** program.

WebXR sessions, controllers, teleport, AR hit-test, spatial UI, comfort, and an honest desktop fallback — not a native-only VR program.

Source of teaching format: [[02 Curriculum Design Advice]]

**Lecture notes:** [[XR/00 Lectures]]  
**Exercises:** [[XR/exercises/00 Index]]

---

## Where this course sits

Semester **5**. [[18 Three.js Development]] and Web Technologies. R3F optional.

---

## Course goal

By the end, a student can ship a one-verb XR experience with comfort defaults and a lab-runnable fallback.

---

## Teaching structure

| Part | Duration | What happens |
| --- | --- | --- |
| Lecture | 75 min | Concepts, one derivation or architecture picture |
| Live coding | 60 min | Professor implements the week's kernel |
| Lab | 2–3 hours | Students finish a starter |
| Homework | 4–6 hours | Code + short written |
| Quiz | 10 min | Definitions and one picture |

**Language / tools:** Three.js WebXR, Chrome, optional Quest. HTTPS/localhost.

Never lecture from slides only.

| Component | Weight | Notes |

## Week-by-week summary

| Week | Topic | Students do |
| ---: | --- | --- |
| 1 | WebXR overview | immersive vs inline |
| 2 | VR session and loop | reference space |
| 3 | Controllers and input | select, squeeze, rays |
| 4 | Locomotion | teleport vs smooth |
| 5 | AR hit-test | plane detection idea |
| 6 | Anchors and persistence | world-locked pose |
| 7 | XR interaction design | affordances, diegetic UI |
| 8 | Midterm and comfort | midterm; IPD, vignette, locomotion policy |
| 9 | Performance in XR | fill rate, foveation name |
| 10 | Spatial UI patterns | menus, keyboards, inventories |
| 11 | Three.js XR helpers | VRButton, controllers |
| 12 | Safety and ethics | boundaries, harassment, medical |
| 13 | A tiny XR experience | one verb |
| 14 | Project studio | XR mini |
| 15 | Presentations | 12+5 |

## What to skip

Unity/Unreal as required, full social XR, OpenXR C++.

---

## Textbooks / refs

Immersive Web working group docs. Three.js XR examples. XR UX articles (selected).

---

## One-sentence teaching principle

If it cannot run inline in the lab, it is not the weekly deliverable — headset is extra evidence.
