# Web Technologies

A 15-week university course for the **Interactive Graphics and Web Technologies (IGWT)** program.

How browsers load, parse, layout, paint, and run script. Students build pages by hand before any framework.

Source of teaching format: [[02 Curriculum Design Advice]]

**Lecture notes:** [[Web Technologies/00 Lectures]]  
**Exercises:** [[Web Technologies/exercises/00 Index]]

---

## Where this course sits

Semester **1**. Programming Week 1–5 in parallel or prior.

---

## Course goal

By the end, a student can ship a responsive, semantic, slightly interactive site, fetch local JSON, and explain the rendering pipeline.

---

## Teaching structure

| Part | Duration | What happens |
| --- | --- | --- |
| Lecture | 75 min | Concepts, one derivation or architecture picture |
| Live coding | 60 min | Professor implements the week's kernel |
| Lab | 2–3 hours | Students finish a starter |
| Homework | 4–6 hours | Code + short written |
| Quiz | 10 min | Definitions and one picture |

**Language / tools:** Editor, browser DevTools, static server. No React.

Never lecture from slides only.

## Week-by-week summary

| Week | Topic | Students do |
| ---: | --- | --- |
| 1 | How the web works | URL, HTTP, browser |
| 2 | HTML structure | tree, tags, a first page |
| 3 | Semantic HTML and forms | nav, main, form controls |
| 4 | CSS box model | margin border padding content |
| 5 | Flexbox | axis, wrap, alignment |
| 6 | Grid | rows, columns, areas |
| 7 | Responsive and media | viewport, breakpoints |
| 8 | Midterm and JS in the page | midterm; script and DOM intro |
| 9 | The DOM | nodes, createElement |
| 10 | Events | bubble, preventDefault |
| 11 | HTTP and fetch | JSON APIs |
| 12 | Browser rendering pipeline | DOM CSSOM layout paint composite |
| 13 | Accessibility and performance | a11y, LCP name |
| 14 | Project studio | portfolio site |
| 15 | Presentations | 12+5 |

## What to skip

React, Next, Tailwind-as-the-course, backend databases.

## One-sentence teaching principle

If they cannot inspect the DOM, they cannot debug a configurator UI on top of WebGL.
