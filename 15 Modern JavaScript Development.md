# Modern JavaScript Development

A 15-week university course for the **Interactive Graphics and Web Technologies (IGWT)** program.

The language and tooling IGWT actually ships: modules, async, npm/Vite, tests, and a game loop.

Source of teaching format: [[02 Curriculum Design Advice]]

**Lecture notes:** [[Modern JavaScript/00 Lectures]]  
**Exercises:** [[Modern JavaScript/exercises/00 Index]]

---

## Where this course sits

Semester **2**. [[12 Introduction to Programming]] and [[13 Web Technologies]].

---

## Course goal

By the end, a student can structure a multi-file JS app, fetch data safely, and test the kernel.

---

## Teaching structure

| Part | Duration | What happens |
| --- | --- | --- |
| Lecture | 75 min | Concepts, one derivation or architecture picture |
| Live coding | 60 min | Professor implements the week's kernel |
| Lab | 2–3 hours | Students finish a starter |
| Homework | 4–6 hours | Code + short written |
| Quiz | 10 min | Definitions and one picture |

**Language / tools:** Browser, Node, npm, Vite. TypeScript optional.

Never lecture from slides only.

## Assessment

| Component | Weight | Notes |
| --- | --- | --- |

## Week-by-week summary

| Week | Topic | Students do |
| ---: | --- | --- |
| 1 | ES6 bindings and arrows | let const arrow |
| 2 | Destructuring and spread | pattern match lite |
| 3 | Modules | export import |
| 4 | Promises | then catch finally |
| 5 | async/await | try/catch, sequential vs parallel |
| 6 | Fetch patterns | JSON, abort, cache |
| 7 | Tooling | npm, vite, scripts |
| 8 | Midterm and types preview | midterm; TS optional |
| 9 | Collections | Map Set |
| 10 | Closures and this | factory, bind |
| 11 | Performance | measure, GC, hot loops |
| 12 | Testing | assert, tiny runner |
| 13 | Patterns for graphics apps | game loop, modules, state |
| 14 | Project studio | small tool |
| 15 | Presentations | 12+5 |
