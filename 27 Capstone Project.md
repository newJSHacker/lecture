# Capstone Project

A 15-week university course for the **Interactive Graphics and Web Technologies (IGWT)** program.

Fifteen weeks of one product: problem, spec, architecture, vertical slice, sprints, midterm demo, freeze, defense — not a new course of topics.

Source of teaching format: [[02 Curriculum Design Advice]]

**Lecture notes:** [[Capstone/00 Lectures]]  
**Exercises:** [[Capstone/exercises/00 Index]]

---

## Where this course sits

Semester **6**. Core IGWT through at least WebGL or Three.js. Staff approve topics that fit the lab.

---

## Course goal

By the end, a team can defend a runnable interactive application with a spec, measured budgets, labeled oracles, and a tagged freeze.

---

## Teaching structure

| Part | Duration | What happens |
| --- | --- | --- |
| Lecture | 75 min | Concepts, one derivation or architecture picture |
| Live coding | 60 min | Professor implements the week's kernel |
| Lab | 2–3 hours | Students finish a starter |
| Homework | 4–6 hours | Code + short written |
| Quiz | 10 min | Definitions and one picture |

**Language / tools:** Whatever the spec allows from IGWT (Canvas through WebXR). No new engine in week 14.

Never lecture from slides only.

---

## Assessment

| Component | Weight | Notes |
| --- | --- | --- |
| Labs (12) | 25% | Must run |
| Homework (8) | 20% | Mix of code and written |
| Quizzes (10) | 10% | Weekly |
| Midterm (Week 8) | 15% | Written |
| Final project | 30% | Demo + 6–8 page report |

---

## Week-by-week summary

| Week | Topic | Students do |
| ---: | --- | --- |
| 1 | Teams and problems | who, why, users |
| 2 | Specification | must / should / skip |
| 3 | Architecture | modules, data, APIs |
| 4 | Vertical slice | one path that works |
| 5 | Sprint: assets and look | budgeted glTF |
| 6 | Sprint: interaction | the verb |
| 7 | Sprint: performance and a11y | measure + keyboard |
| 8 | Midterm demo | public checkpoint |
| 9 | Sprint: content completeness | copy, data, beats |
| 10 | Sprint: robustness | load fail, bad GLB, offline |
| 11 | Sprint: documentation | README, video, report outline |
| 12 | Sprint: rehearsal | 12+5 practice |
| 13 | Polish freeze approaching | bugs only |
| 14 | Freeze week | tag, report, video |
| 15 | Defense | 12+5 public |

---

## What to skip

A second thesis, a startup pitch without software, unlabeled asset dumps.
