# Introduction to Programming

A 15-week university course for the **Interactive Graphics and Web Technologies (IGWT)** program.

Students learn computational thinking in **JavaScript** so later Canvas, WebGL, and Three.js are the same language. Python is allowed only if the department already uses it for all Semester 1 labs.

Source of teaching format: [[02 Curriculum Design Advice]]

**Lecture notes:** [[Programming/00 Lectures]]  
**Exercises:** [[Programming/exercises/00 Index]]

---

## Where this course sits

Semester **1**. No prior coding required. Keyboard literacy yes.

---

## Course goal

By the end, a student can write functions, arrays, objects, a search, a sort, a recursive base case, and tests — and explain a stack trace.

---

## Teaching structure

| Part | Duration | What happens |
| --- | --- | --- |
| Lecture | 75 min | Concepts, one derivation or architecture picture |
| Live coding | 60 min | Professor implements the week's kernel |
| Lab | 2–3 hours | Students finish a starter |
| Homework | 4–6 hours | Code + short written |
| Quiz | 10 min | Definitions and one picture |

**Language / tools:** Browser + editor + Git. Node optional. No frameworks.

Never lecture from slides only.

---

## Assessment

| Component | Weight | Notes |
| --- | --- | --- |
| Labs (12) | 25% | Must run |
| Homework (8) | 20% | Mix of code and written |
| Quizzes (10) | 10% | Weekly |
| Midterm (Week 8) | 15% | Written |
| Final project | 30% | Demo + 6–8 page report |

---

## Week-by-week summary

| Week | Topic | Students do |
| ---: | --- | --- |
| 1 | What a program is | values, console, a first script |
| 2 | Variables and strings | let, const, template strings |
| 3 | Conditions | if / else / comparisons |
| 4 | Loops | for, while, off-by-one |
| 5 | Functions | parameters, return, scope |
| 6 | Arrays | push, map, index |
| 7 | Objects | records, nested data |
| 8 | Midterm and debugging | midterm; then debugger |
| 9 | Search | linear vs binary |
| 10 | Sorting and complexity | selection sort; Θ |
| 11 | Recursion | base case, stack |
| 12 | Modules and structure | split files, functions as API |
| 13 | Objects as programs | tiny OOP, methods |
| 14 | Project studio | console or canvas mini-game |
| 15 | Presentations | 12+5 |

---

## What to skip

TypeScript, React, algorithms research, big-O proofs beyond nested loops.

---

## Textbooks / refs

MDN JS guide. Eloquent JavaScript (selected chapters). Department Python book only if Python is the language.

---

## One-sentence teaching principle

If they cannot write a loop and a function, they cannot write a renderer.
