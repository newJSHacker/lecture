# Geometry kernel and demos

Teaching Canvas demos for [[Computational Geometry/00 Lectures]].

- Open [index.html](index.html).
- Copy functions from [kernel.js](kernel.js). Prefer copying into a student starter over importing this file forever.
- [viz.js](viz.js) is click-to-add / drag-to-move / right-click-delete. Not a production viewer.

If a browser blocks `file://` scripts, serve this folder:

```
npx serve
python -m http.server
```
